## Завдання 1. Пошук мінімального та максимального елементів

Реалізовано функцію `find_min_max`, яка знаходить мінімальний та максимальний елементи у масиві за допомогою підходу **«розділяй і володарюй»**.

### Особливості реалізації

- функція приймає масив чисел довільної довжини;
- використовується рекурсивний підхід;
- масив рекурсивно ділиться на частини;
- функція повертає кортеж:

```python
(minimum, maximum)
```

- часова складність алгоритму:

```text
O(n)
```

### Приклад

```python
numbers = [3, -5, 10, 2, 8, 0, 15, -2]

minimum, maximum = find_min_max(numbers)

print(minimum)
print(maximum)
```

Результат:

```text
-5
15
```

## Завдання 2. Оптимізація черги 3D-принтера

Реалізовано функцію `optimize_printing`, яка оптимізує порядок виконання завдань 3D-друку з урахуванням:

- пріоритету завдань;
- максимального допустимого об'єму;
- максимальної кількості моделей для одночасного друку;
- часу друку моделей.

Для структур даних використовуються `dataclass`:

```python
@dataclass
class PrintJob:
    id: str
    volume: float
    priority: int
    print_time: int
```

```python
@dataclass
class PrinterConstraints:
    max_volume: float
    max_items: int
```

### Пріоритети

- `1` — курсові та дипломні роботи;
- `2` — лабораторні роботи;
- `3` — особисті проєкти.

Завдання з вищим пріоритетом виконуються раніше.

### Жадібний алгоритм

Алгоритм:

1. Сортує завдання за пріоритетом.
2. Послідовно формує групи моделей.
3. Додає модель до поточної групи, якщо не перевищено:
   - `max_volume`;
   - `max_items`.
4. Якщо наступна модель не поміщається, поточна група завершується.
5. Час друку групи визначається як максимальний час друку серед моделей цієї групи.

Наприклад:

```text
M1: 120 хв
M2: 90 хв
```

Якщо обидві моделі можна друкувати одночасно, час групи:

```text
max(120, 90) = 120 хв
```
